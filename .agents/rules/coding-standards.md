# Codebase Standards

- All package commands must use `bun` or `bunx`.
- Ensure high-DPI canvas rendering (`1080x1080` for Format A, `1200x640` for Format B).
- Keep component styling in neo-brutalist dark mode theme (`#07150E`, `#0D2419`, `#FFDF00`, `#FF007A`).
- Dynamic URL parameter state hydration is handled in `App.jsx`.
